# 🎓 Student Management System

A simple and interactive **Student Management Web Application** built using **HTML, CSS, JavaScript, and jQuery**. This project allows users to register, log in, and manage student records efficiently.

---

## 🚀 Features

* 🔐 User Authentication (Signup & Login)
* ➕ Add Student Records
* 📋 Display All Students
* 🗑️ Delete Student Records
* 📊 Live Student Count
* ⚠️ Form Validation with User-Friendly Messages
* 🎨 Clean and Responsive UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* jQuery

## ⚙️ How It Works

### 1. Signup

* User creates an account using name, email, and password.
* Data is stored temporarily in an array.

### 2. Login

* User logs in with registered credentials.
* If valid → Dashboard opens.

### 3. Dashboard

* Add student (Name, Age, Course)
* View all students
* Delete any student
* Live student count updates automatically
